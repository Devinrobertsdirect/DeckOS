1.3 User Characteristics
The Hardware Hacker / Maker: This user relies on Raspberry Pi and Arduino hardware. They need a system that sits on top of standard Linux without heavy overhead so they can run custom Python scripts, monitor sensor data, and interface with GPIO pins directly from the dashboard.

The Cybersecurity Enthusiast: A student or hobbyist using the deck for penetration testing or network administration. They require fast, keyboard-driven access to tools like nmap and system logs without navigating a bloated desktop GUI.

The Off-Grid Operator: An individual using the cyberdeck in remote locations. Their primary need is robust offline capability, relying heavily on local LLMs (Ollama) and downloaded Wikipedia files.
+1

The Distraction-Free Developer: A programmer utilizing the cyberdeck as a specialized, self-contained coding environment. They appreciate the cyberpunk aesthetic and the strict monospace, terminal-first interface  for maintaining deep focus.
